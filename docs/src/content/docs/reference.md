Every module's interface, generated by odoc from its `.mli`, where each
function says what it does, what it refuses and what it defaults to.

## The packages

Each package is separate, so a program links only what it uses. A `dune`
file names a library as it is installed (`rowtype-postgres`); OCaml code
names it as a module (`Rowtype_postgres`).

| Package | Libraries | What it is |
|---|---|---|
| `rowtype` | `rowtype` | Queries described once; links no database library |
| `rowtype-postgres` | `rowtype-postgres` | The Postgres backend, over [postgres-eio](https://hyphatech.github.io/postgres-eio/) |
| `rowtype-sqlite` | `rowtype-sqlite` | The SQLite backend, over the [sqlite3](https://github.com/mmottl/sqlite3-ocaml) binding |
| `rowtype-migrate` | `rowtype-migrate`, `rowtype-migrate.postgres`, `rowtype-migrate.sqlite` | The migrations and the `rowtype-migrate` command, for each dialect installed beside it |

## rowtype

- [`Rowtype`](/rowtype/reference/rowtype/Rowtype/index.html) -- shapes,
  statements, errors, and the signature a backend fills.
- [`Rowtype_postgres`](/rowtype/reference/rowtype-postgres/Rowtype_postgres/index.html)
  -- connections, the pool, notifications, transactions, `COPY` and
  `verify` on Postgres. Its parts:
  [`Pool`](/rowtype/reference/rowtype-postgres/Rowtype_postgres/Pool/index.html),
  [`Listener`](/rowtype/reference/rowtype-postgres/Rowtype_postgres/Listener/index.html)
  and
  [`Transaction`](/rowtype/reference/rowtype-postgres/Rowtype_postgres/Transaction/index.html).
- [`Rowtype_sqlite`](/rowtype/reference/rowtype-sqlite/Rowtype_sqlite/index.html)
  -- connections, the pool, transactions, the load and `verify` on SQLite.
  Its parts:
  [`Pool`](/rowtype/reference/rowtype-sqlite/Rowtype_sqlite/Pool/index.html)
  and
  [`Transaction`](/rowtype/reference/rowtype-sqlite/Rowtype_sqlite/Transaction/index.html).
- [`Rowtype_migrate`](/rowtype/reference/rowtype-migrate/Rowtype_migrate/index.html)
  -- the files, the record and its rules, the same for every dialect.
- [`Rowtype_migrate_postgres`](/rowtype/reference/rowtype-migrate/Rowtype_migrate_postgres/index.html)
  -- migrating Postgres.
- [`Rowtype_migrate_sqlite`](/rowtype/reference/rowtype-migrate/Rowtype_migrate_sqlite/index.html)
  -- migrating SQLite.

## What it is built on

- [`Postgres_eio`](https://hyphatech.github.io/postgres-eio/) -- the
  driver under `rowtype-postgres`, whose connection strings, pool and
  listener it passes through.
